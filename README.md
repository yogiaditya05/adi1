# Student Results Portal

A premium, modern Student Results Portal for **Aditya Yogi (Roll No: 0827rl231005)**.

## 🚀 Live Demo
[View Live Site](https://adityayogi.netlify.app)

## ✨ Features
- **Modern UI/UX**: Built with a sleek dark mode aesthetic, vibrant accents, and smooth scroll animations.
- **Live Data**: Fetches student results in real-time from a Postman Mock API.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Personalized**: Highlights the student's own record in the results list.
- **Contact Integration**: Mock contact form for inquiries.

## 🛠️ Technology Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Backend**: Postman Mock API.
- **Deployment**: Netlify.
- **Version Control**: Git & GitHub.

## 📈 Performance
- Optimized typography using Google Fonts (Space Grotesk & DM Serif Display).
- Glassmorphism effects and subtle micro-animations for a premium feel.
